# Android starter

Open this directory in Android Studio with SDK 35, JDK 17 and Gradle 8.9. Sync, choose `demoDebug` and run on Android 12 or newer. CLI equivalent with a local Gradle 8.9 install is `gradle :app:assembleDemoDebug`. Camera and BLE require a physical phone. GPS, camera, Bluetooth and SMS each have independent permission and failure paths.

1. Turn on only the intended stick for enrollment. Press **Find and connect to stick** and enter its serial pairing PIN in Android's pairing dialog. Disconnect the stick to verify the dashboard is cleared. The active in-process connection retries with the selected bonded device. After app restart, use the connect button again.
2. Enter up to five contact phone numbers, one per line. Save and allow precise location if you want a fix. Start **Simulate a fall** and exercise both cancel and expiry. Simulated events never send.
3. Start phone SOS or hold the cane button for 1.5 seconds. At 20 seconds the demo build enables **Open SMS draft for a contact**. Choose a contact then press Send in your SMS app. A missing or stale fix produces a message without coordinates.
4. For approved bench recipient numbers only, `gradle :app:assembleLabDebug` builds a separate sideload package. Grant SMS, select a default SIM, arm the lab switch, then leave the app visible for the real-event countdown. This submits one SMS per saved contact after expiry. The current demo shows the latest platform send result. Confirm actual delivery separately at each recipient. There is no automatic retry.
5. Enter the camera SSID and WPA2 key printed at enrollment. Accept Android's connection request. The app fetches and decodes JPEGs over that specific network. To enable offline classification, follow the export instructions in `../ai/model_research/README.md` and package the local ONNX file. Without it the same app exercises JPEG transport. The model binary is not bundled.

The app uses ordinary accessible controls, status text and optional offline TTS. The current strings are English. Test TalkBack, large font, location denied, screen lock, app removal and Bluetooth toggles on two phones. The Activity is the only lifecycle owner in this starter. Expiry while hidden can prepare a draft in memory, and process death loses countdown and connection. Automatic SMS and continuous fall sensing are foreground-only here. The foreground-service design and release restrictions are documented in the technical architecture.
