# Vision measurements

Log Android model hash, phone and OS, camera geometry, dataset split, session start and thermal state. Collect at least 30 opportunities for each priority class and at least 100 negative frames per tested lighting band. Score per-class precision/recall and false spoken alerts per minute. Raw frame metrics and spoken event metrics are separate. Report median, p95 and sustained processed FPS including decode and dropped attempts at 1, 5 and 15 minutes. Use an external time-coded LED/video reference for end-to-end lag. No observations are prefilled.
